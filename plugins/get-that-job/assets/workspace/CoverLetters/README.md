# Cover-letter sources

Chosen cover-letter design reference: `Template/GetThatJob_Default_Cover_Letter_Style.docx` (generic default).

If you prefer your own letter design, add an approved reference in `Template/` and tell GetThatJob which filename to use. Record that filename above. The design reference controls layout only; actual letter content must come from verified applicant information and the live role. Preserve originals. New role-specific letters belong in `../applications/<ID>/`, beside that role's other materials. Employer requirements can still determine the final file format.
