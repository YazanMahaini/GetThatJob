# Application packet guide

Create one folder per real opportunity, named with its stable `APPLICATIONS.csv` ID. In that folder, keep a `README.md` recording:

1. Employer, role, requisition, live URL, date checked, deadline, compensation, eligibility, and application route.
2. Duties and essential requirements, each marked met, unclear, or unmet with specific source evidence.
3. The approved CV used, changes made, cover letter and extra files, unanswered fields, and visual/document checks. Pair each new Word document with a same-stem PDF.
4. Portal draft location and saved state; the standing submission mode and who took the final action; later submission and confirmation evidence.

Keep the original CVs and credential documents in their source folders. Use the user's document style and the format the employer requests. The plugin imposes no visual design. Use PDFs for review and uploads unless the employer requests another format.
