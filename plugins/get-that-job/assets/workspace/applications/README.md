# Application packet guide

Create one folder per real opportunity, named with its stable `APPLICATIONS.csv` ID. In that folder, keep a `README.md` recording:

1. Employer, role, requisition, live URL, date checked, deadline, compensation, eligibility, and application route.
2. Duties and essential requirements, each marked met, unclear, or unmet with specific source evidence.
3. The approved CVs used for facts, the separate CV design reference, changes made, cover letter and extra files, unanswered fields, and visual/document checks. Pair each new Word document with a same-stem PDF.
4. Whether the applicant selected this specific opportunity, or which explicit standing automatic opportunity scope covers it; record the source/date of that decision separately from search fit and the submission mode.
5. Portal draft location and saved state; the standing submission mode and who took the final action; later submission and confirmation evidence.

Keep the original CVs and credential documents in their source folders. Use the applicant's chosen CV design reference and the format the employer requests. The plugin imposes no visual design. Use PDFs for review and uploads unless the employer requests another format.
